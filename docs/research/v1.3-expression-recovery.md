# AnifLive-TTS v1.3 Expression Recovery

## Decision

The reference-directed expression hypothesis is validated. Automated
release-qualification gates pass for both Miku and Roxy, and the independent
blinded-listening gate is complete. The implementation is release-qualified.

The recovery work starts from immutable v1.2 commit
`e8386758ac3629483c8ca761f42c3b96f58144e0` and the preserved v1.3 expression
baseline. It does not reopen the rejected v1.3 latency architectures.

## Frozen Failure Baseline

- Roxy controlled expression: 16/16 rows pass.
- Roxy controlled streaming: 48/48 runs without underrun.
- Roxy neutral controls: 2/2 rows pass.
- Miku controlled expression: 15/16 rows pass.
- Miku controlled streaming: 48/48 runs without underrun.
- Miku long `languid`: exact semantics, speaker cosine `0.999274`, duration
  difference below `0.04%`, log-mel cosine `0.988959`.
- Miku neutral output remains v1.2-equivalent.

The Miku neutral playback finding was reclassified: the old matrix used a
zero-prebuffer stress model while the API and WebUI use a documented 32 or 64
ms prebuffer. Both measurements remain visible, but only the contractual model
is a release playback gate.

## Completed Recovery

1. Preserve machine-readable baseline evidence and effective runtime settings.
2. Replace the zero-prebuffer-only matrix gate with a canonical integer-sample
   playback model and retain zero-prebuffer gaps as diagnostics.
3. Compare raw and normalized stream/complete output domains.
4. Localize divergence in time and identify the first acoustic operation that
   introduces it.
5. Evaluate exact future-context first preview at 17, 25, 33, and 41 tokens.
6. If required, evaluate deferred onset, stable-prefix commit, refill alignment,
   and latent alignment in that order.
7. Encode the selected runtime and public conditioning policy reproducibly.
8. Re-run every previously passing Miku and Roxy case, then five languages and
   independent blinded listening.

for both models:

The post-policy five-language matrix then tested neutral and `languid`

Neutral complete WAV, streaming PCM, semantic output, and streaming semantic
output remain exactly equal to the immutable v1.2 baseline for both models in
all five languages. Real API acceptance also passes complete and streaming
requests, legacy adapters, model switching, cancellation recovery, TensorRT 11
reporting, and the no-PyTorch-fallback contract.

A bounded same-round direct-service regression diagnostic found no neutral
performance regression. Miku first-packet P50 changed from `57.258 ms` to
`53.068 ms` and complete RTF from `0.077591` to `0.073215`. Roxy first-packet
P50 changed from `59.630 ms` to `59.133 ms` and complete RTF from `0.096680` to
`0.094847`. These values are regression diagnostics, not the canonical public
HTTP benchmark and do not replace README performance claims.

The canonical Roxy-only HTTP benchmark then ran 10 sessions with 10 warmups
and 100 complete, 100 new-connection stream, and 100 keep-alive stream requests
per session. Keep-alive audible TTFA P50 was `74.578 ms`, complete-WAV RTF P50
was `0.087680`, and all 3,000 formal requests reported TensorRT 11 with no
PyTorch neural fallback.

The final blind pack contained six short, long, and mixed-expression pairs.
Five were judged to have no meaningful difference; one Roxy long-form pair
preferred the complete output. No artifact was reported. The blind gate passes
without weakening any objective threshold.
