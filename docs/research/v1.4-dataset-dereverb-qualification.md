# Dataset Factory Dereverb Qualification

Status: **NO-GO for v1.4**  
Audit date: 2026-08-31

## Release Contract

A Dataset Factory dereverb backend can be enabled only when all of the following are true:

- execution is confined to the pinned Linux Docker worker;
- source and model revisions are fixed and included in the worker fingerprint;
- every model asset has redistribution terms compatible with AnifLive-TTS;
- request-time downloads and network access are disabled;
- output is deterministic for the same audio, configuration and worker image;
- speech-content, speaker-identity and artifact checks pass on a fixed corpus;
- the original input and dereverberated output are both retained for review.

The runtime therefore accepts only `dereverb_backend=none` until a backend passes this
contract. Any other value fails the job instead of silently skipping dereverberation.

## Local Asset Audit

The development host contained no complete, locally cached dereverberation checkpoint that
could be mounted into the worker. One cache entry had only a revision pointer and no snapshot or
weight blobs. A separate locally installed enhancement runtime was also inspected, but its own
release notice explicitly restricted the bundle to private, non-commercial use. It cannot be a
redistributable AnifLive-TTS dependency.

The pinned workstation worker consequently contains no qualified dereverb model, model manifest
or release-compatible license notice. Downloading a model while a Dataset Factory job is running
would break the offline and immutable-provenance requirements.

## Decision

Dereverberation remains visibly unavailable in v1.4. This is a backend qualification failure,
not a successful or simulated processing stage. `ffmpeg-afftdn` remains an independently labeled,
optional conservative denoiser; it is not described as dereverberation.

Reconsideration requires a separately supplied local backend and a machine-readable report with:

- source revision and license identifier;
- every model file SHA-256;
- worker image digest and runtime versions;
- fixed-corpus waveform hashes and repeatability evidence;
- content, speaker-similarity and reverberation metrics;
- an explicit pass/fail decision against the release contract above.
